# 蓝牙触控板 / 飞鼠

## 使用方法
1. 打开「设备详情」→「蓝牙触控板 / 飞鼠」，不需要连接 ADB。
2. 允许“附近的设备”权限并开启蓝牙。Android 9 以下显示不支持，不影响原有功能。
3. 首次使用，点击「让目标设备发现此手机」，在系统弹窗中允许临时可发现。
   在目标电脑、电视或设备的蓝牙设置中搜索手机并完成配对。
4. 返回此页，点击「授权 / 刷新」，选择已配对目标。只有连接回调确认成功后才启用输入。
5. 使用触控板、左右键、滚轮和拖拽；需要飞鼠时开启下方开关，静止校准后移动手机。
6. 「断开 / 切换设备」释放当前连接并回到设备选择。

## 边界与异常
- 手机需要 Android 9/API 28 以上并支持 Bluetooth HID Device。系统版本满足不代表厂商实现一定支持。
- Android 12 以上使用 BLUETOOTH_CONNECT；仅请求可发现时使用 BLUETOOTH_ADVERTISE。
  本功能不在应用内扫描，因此不请求扫描或定位权限。
- 目标需要支持标准蓝牙 HID 鼠标；实际兼容性必须通过真机验证。
- 注册或连接超过 15 秒会退出等待并显示错误。可检查系统蓝牙设置后重试。
- 只连接用户明确选择的已配对设备；不自动控制其他接入的设备，不后台重连。
- 离开页面或进入后台停止传感器和报告发送，发送松键报告、断连并注销 HID。
  返回后需要重新选择目标。系统断开、撤销权限、虚拟线缆解除均停止输入。
- 保留现有鼠标协议、手势和陀螺仪算法，发送四字节 HID 输入；Boot 模式发送三字节无滚轮报告。
- 蓝牙键盘、中文文本输入和自定义按键不在 v1.4 本次交付范围。

## 真机验收
- Android 9–11 与 Android 12+ 的权限、关闭蓝牙、拒绝权限、重新授权路径。
- 首次配对、已有配对、目标不支持、连接超时、目标关机、手机关闭蓝牙。
- 移动、左右键、双指滚轮、拖拽后点击、拖拽时退出/锁屏/切换应用。
- 飞鼠开关、校准、横竖屏、无陀螺仪、静止漂移、长时间控制。
- 不连接 ADB 时可独立使用；ADB 配对、USB、屏幕镜像仍能正常使用。
- 快捷操作排序、取消、保存、恢复默认及进程重启后顺序保留。
