# SkyADB Pro v1.3.0 更新报告

发布日期：2026-10-28。版本号：1.3.0；Android versionCode：101309。
正式应用标识：io.github.woinjun.skyadbpro。

## 新增功能

- **ADB 触控板**：独立控制页面，支持单指相对移动、轻触点击、左右键、双指上下滚轮，以及保持左键拖动。
- **ADB 陀螺仪飞鼠**：通过控制手机的陀螺仪移动目标设备指针；提供启动静止校准、重新校准、灵敏度调节、滤波及横竖屏轴映射。
- **输入生命周期管理**：退出页面、切换到后台、连接中断或服务器报错时停止鼠标输入并释放虚拟设备。
- **兼容性提示**：检测目标设备 UHID 访问能力；本机无陀螺仪时禁用飞鼠，保留触控板。

## 使用方法

先通过 WiFi ADB、无线调试配对或 USB ADB 连接设备，
进入「设备详情 → ADB 触控板 / 飞鼠」，点击「启动控制」。
启用飞鼠后请先竖握手机并保持静止约一秒，再转动手机。
目标设备需要支持且允许 ADB shell 使用 UHID。

## 项目与发布维护

- 应用名称调整为 **SkyADB Pro**。
- 设置中的项目地址改为 https://github.com/woinjun/skyadb-pro，
  并保留 sky22333/skyadb 原项目来源入口。
- 正式版使用独立包名与固定 RSA 3072 位 PKCS12 签名，支持后续同包名、同证书且更高 versionCode 的覆盖升级。
- 发布流程核对签名证书指纹，并提供 APK SHA-256 校验文件。
- 保留原有 ADB 配对、USB/Fastboot、镜像、镜像键盘、遥控器、文件与应用管理功能。

## 验证与已知限制

本地正式签名 Release 构建、R8 优化与 73 项 JVM 单元测试（新增 9 项）均通过；
Release Lint 为 0 错误、64 条警告，APK 签名证书与固定指纹一致。
尚未执行真机/仪器测试，无法保证所有手机或电视的手势、漂移、延迟和 UHID 兼容性。
旧系统或厂商策略可能阻止 UHID；校准时移动手机可能导致指针漂移，请重新校准。

**蓝牙 HID 飞鼠、蓝牙 HID 鼠标/键盘、独立完整键盘与自定义遥控器未在本版实现。**
后续先根据 ADB 输入真机反馈修正，再开展蓝牙 HID 迭代。

## 安装与升级

本正式版可与原版及此前 Debug 测试包并存，其本地设置独立，不会自动迁移。
后续升级请使用本项目固定签名正式 APK；提高 versionCode 不能绕过签名不一致。
请从本仓库 Releases 下载并核对 SHA256SUMS。
