# SkyADB Pro v1.4.0 更新说明

## 新增
- 蓝牙 HID 触控板、鼠标和陀螺仪飞鼠，可在没有 ADB 连接时使用。
- 配对引导、附近设备权限、设备选择、超时和断连提示。
- 快捷操作排序：长按手柄拖动、上下移动、保存、取消和恢复默认；顺序在重启后保留。

## 改善
- ADB 触控板进入页面自动准备控制，取消日常启动/停止按钮；失败可重试。
- 陀螺仪飞鼠保持下方独立开关，默认关闭。
- 共用触控和飞鼠输入处理，点击时正确释放此前保持的拖拽。
- 页面退出或进入后台停止输入并释放会话。

## 版本与兼容性
- 版本 1.4.0，versionCode 101409。
- 正式应用标识仍为 io.github.woinjun.skyadbpro；保持原固定签名。
- 蓝牙 HID 需要 Android 9+ 及手机厂商支持，目标设备须支持 HID 鼠标。
- 蓝牙键盘、自动化遥控器及应用内更新未纳入此版。

这是待验收的开发版本说明。发布前须完成真实设备连接、输入、锁屏释放及正式版覆盖升级验证。
构建与单元测试通过不等于蓝牙设备兼容性已经验收。
